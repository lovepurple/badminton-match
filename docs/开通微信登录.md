# 开通微信登录：需要申请什么

面向从没做过微信开发的人。先看结论，再看清单。

## 0. 先分清你需要哪一档

| 档位 | 能实现 | 需要什么 | 成本 | 时间 |
| --- | --- | --- | --- | --- |
| A. 不接微信身份 | 现在的全部功能（建赛、报名链接、记分、实时比分、汇总、导航） | 一个能跑 Python 的服务器（家里电脑也行） | 0 | 0 |
| B. 联调验证 | 微信内静默登录、微信内置地图 | 微信公众平台**测试号**（免费）+ 一个域名 | 约 50 元/年（域名） | 1 天 |
| C. 正式上线 | 同上 + 稳定可用 | **已认证的服务号** + 备案域名 + 公网服务器 | 约 300 元/年 + 域名 + 服务器 | 1～3 周 |

**关键限制（官方规定）**：微信网页授权**只有「已认证的服务号」能用**，订阅号、未认证服务号、小程序都不行
（[官方说明](https://developers.weixin.qq.com/doc/service/guide/h5/auth)：“网页授权支持已认证的服务号使用，其他类型账号均不支持”）。

而**服务号只能由企业/个体工商户/政府/媒体等组织主体注册，个人身份证不能注册服务号**。
所以如果你是个体玩票：

- 想零成本：走 A 档，用手机浏览器打开 H5，输名字报名，功能一样全。
- 想用微信身份：办一个**个体工商户营业执照**（很多地方线上当天可办），再用它注册服务号。

## 1. 正式上线需要申请/准备的东西

| # | 东西 | 在哪办 | 费用 | 耗时 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 1 | 营业执照（企业或个体工商户） | 市场监管局 | 个体户基本免费 | 1～3 天 | 个人身份证不能注册服务号 |
| 2 | 服务号 | <https://mp.weixin.qq.com> → 立即注册 → 服务号 | 免费 | 1 天 | 一个邮箱只能注册一个 |
| 3 | 微信认证 | 公众平台 → 设置与开发 → 微信认证 | **300 元/年** | 1～7 天 | 认证后才有「网页授权」权限 |
| 4 | 域名 | 阿里云/腾讯云购买 | 30～80 元/年 | 即时 | 建议 `.com`/`.cn` |
| 5 | ICP 备案 | 服务器厂商的备案系统 | 免费 | 7～20 天 | 域名必须备案才能配到公众号 |
| 6 | 公网服务器 | 阿里云/腾讯云轻量应用服务器 | 24～100 元/月 | 即时 | 最低配够用 |
| 7 | HTTPS 证书 | 云厂商免费 DV 证书 | 免费 | 10 分钟 | 微信内必须 https |

不需要申请的东西（别被代办忽悠）：微信支付、微信开放平台、UnionID、订阅消息、小程序。
我们只用了「网页授权」和「JS-SDK 地图」两项能力。

## 2. 拿到账号后的后台配置（4 处）

登录 <https://mp.weixin.qq.com>：

1. **AppID / AppSecret**
   设置与开发 → 基本配置 → 开发者 ID。AppSecret 只显示一次，复制到 `server/.env`。
2. **IP 白名单**
   同页 → IP 白名单 → 填**服务器公网 IP**（不是域名）。
   不加白名单，服务端拿 `access_token` 会报 `40164 invalid ip`。
3. **网页授权域名**
   设置与开发 → 公众号设置 → 功能设置 → 网页授权域名 → 填 `your-domain.com`
   （只填域名，**不能带 https://、路径、端口**）。
4. **JS 接口安全域名**
   同一页 → JS 接口安全域名 → 填同一个域名。
   官方限制：不支持 IP 和端口、必须 ICP 备案、新备案域名需 24 小时后才能配置、最多 5 个
   （[JS-SDK 文档](https://developers.weixin.qq.com/doc/service/guide/h5/jssdk.html)）。

然后把域名解析到服务器，配好 HTTPS，再改 `server/.env`：

```bash
GORILLA_WECHAT_APPID=wx1234567890abcdef
GORILLA_WECHAT_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
GORILLA_OAUTH_CALLBACK=https://your-domain.com/api/auth/wechat/callback
GORILLA_ADMIN_DEVICES=你的设备id   # 可选，否则首个登录用户自动成为管理员
```

重启服务，检查：

```bash
curl -s https://your-domain.com/api/health
# "features": {"wechatOAuth": true, "wechatJssdk": true}
```

在微信里打开 `https://your-domain.com/h5/`，会看到地址栏闪一下授权跳转，回到应用即是微信身份
（用户 ID 变成 `wx_<openid>`）。

## 3. 只想先联调（B 档，不认证）

1. 打开微信公众平台「测试号」<https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login>，微信扫码。
2. 页面直接给你 `appID` / `appsecret`（无需营业执照、无需认证）。
3. 在「网页服务 → 网页账号 → 网页授权获取用户基本信息」里填「授权回调页面域名」，
   填你服务器的域名（测试号也不能填 IP）。
4. 把这两个值填进 `server/.env`，`GORILLA_OAUTH_CALLBACK` 用 `https://你的域名/api/auth/wechat/callback`。
5. 重启，用微信打开 H5 验证。

测试号仅用于开发调试，不能对外长期使用；正式上线仍要服务号 + 认证。

## 4. 常见被拒/踩坑

| 现象 | 原因 |
| --- | --- |
| 后台看不到「网页授权」 | 服务号没认证（订阅号/个人号没有） |
| 授权页报 `redirect_uri 参数错误` | 回调域名与后台「网页授权域名」不一致，或带了端口/路径 |
| 报 `40164 invalid ip` | 服务器公网 IP 没加进 IP 白名单 |
| JS-SDK 报 `invalid signature` | 签名用的 URL 与实际页面 URL 不一致（含 hash 差异），或域名不在 JS 安全域名里 |
| 填域名时提示不可用 | 域名未备案，或备案未满 24 小时 |
| 微信里打开一片空白 | 用了 http，微信内部分能力要求 https |

## 5. 我们的代码已经准备好了

- 服务端：`/api/auth/wechat/start`、`/callback`、`/api/wechat/jssdk`（`server/app/main.py`）
- 前端：微信内自动静默授权、带 token 回跳、失败回退设备号（`h5/js/app.js`）
- 配置：`server/.env.example` → 复制成 `server/.env`
- 测试：`server/tests/test_wechat_login.py`（6 项，不需要公众号也能跑）

没有配置时全站用设备号登录，所有业务功能可用——所以你可以先用 A 档把比赛跑起来，
什么时候有空再去办服务号。
