# 微信登录与比赛流程

目标流程：

```
管理员登录 → 创建比赛 → 生成链接 → 成员点链接微信登录报名
→ 满员后管理员开始 → 队员实时看比分 → 结束汇总成绩与详情
```

> 身份说明：微信用户是 `wx_<openid>`，设备号用户是 `dev_<deviceId>`，两者是不同账号。

> 需要统一时可按 `unionid` 合并，或在登录页提供「绑定」入口（当前未实现）。

## 1. 登录方案（H5）

H5 在微信内打开时，用**公众号网页授权**拿 openid；不在微信内（电脑浏览器、分享到 QQ 等）时降级为设备号登录。

| 场景 | 方案 | 需要什么 |
| --- | --- | --- |
| 微信内打开 H5 | 网页授权 `snsapi_base`（静默，仅拿 openid） | 已认证**服务号** + 网页授权域名 |
| 非微信环境 | `deviceId` 登录（浏览器生成并持久化） | 无 |

官方依据：

- [微信网页授权](https://developers.weixin.qq.com/doc/service/guide/h5/auth) —— 四步：跳转授权页 → 回调拿 `code` → 换 `access_token`/`openid` → 拉用户信息（`snsapi_userinfo` 才有昵称头像）。
- [授权登录常见问题](https://developers.weixin.qq.com/doc/oplatform/developers/troubleshooting/auth.html) —— 网页授权只有**认证的服务号**支持；`snsapi_base` 静默、`snsapi_userinfo` 弹窗。
- 小程序 `code2Session`（本项目已不使用，仅备查）：[小程序登录凭证校验](https://developers.weixin.qq.com/miniprogram/dev/server/API/user-login/api_code2session.html)。

### 服务端实现（已完成）

| 接口 | 作用 |
| --- | --- |
| `GET /api/auth/wechat/start?redirect=/h5/...` | 302 到 `open.weixin.qq.com/connect/oauth2/authorize`，带 `state` |
| `GET /api/auth/wechat/callback?code=&state=` | 用 code 换 openid → 建用户 → 签发本站 token → 302 回 `redirect?token=...` |
| `POST /api/auth/login` | 设备号登录（默认降级路径） |

H5 启动时读取 `?token=` 并写入本地存储后清除该参数；令牌失效（401）会自动清空并重新登录一次。

### 需要你准备的配置

```bash
# server/.env 或启动环境变量
GORILLA_WECHAT_APPID=wx...           # 认证服务号 AppID
GORILLA_WECHAT_SECRET=...            # 服务号 AppSecret
GORILLA_OAUTH_CALLBACK=https://你的域名/api/auth/wechat/callback
GORILLA_PUBLIC_BASE=https://你的域名  # 可选，用于生成分享链接
```

公众号后台还需要：

1. **接口权限 → 网页服务 → 网页授权获取用户基本信息** 已开通（认证服务号默认有）。
2. **网页授权域名** 填写你的域名（需已备案、可访问，且不能带路径）。
3. 服务器用 HTTPS（微信内 H5 建议强制 https）。

未配置时 `/api/health` 返回 `features.wechatOAuth = false`，前端自动只用设备号登录，本地开发无需任何公众号配置。

## 2. 流程与接口

```
管理员                         服务端                          成员
  │ POST /api/races              │                              │
  │─────────────────────────────▶│  创建（status=draft）         │
  │ POST /api/races/{id}/open    │                              │
  │─────────────────────────────▶│  生成 joinCode，status=open   │
  │  分享链接 #/join/{code}       │                              │
  │                              │◀─────────────────────────────│ 打开链接
  │                              │  GET /api/join/{code}         │
  │                              │◀─────────────────────────────│ 微信授权 → token
  │                              │  POST /api/races/{id}/join    │
  │                              │─────────────────────────────▶│ 报名成功
  │ POST /api/races/{id}/start   │                              │
  │  (players+matches)           │  status=playing              │
  │─────────────────────────────▶│                              │
  │ PUT /api/races/{id}/matches/{mid}                           │
  │─────────────────────────────▶│◀─────────────────────────────│ GET /live?since=
  │ POST /api/races/{id}/finish  │                              │
  │─────────────────────────────▶│  status=done                 │
  │                              │◀─────────────────────────────│ GET /summary
```

要点：

- **对阵生成在管理员浏览器里做**（`shared/formats.js`），开始时随 `POST /start` 一起提交；服务端只做校验与存储，避免两套算法。
- **权限**：只有创建者能开放报名、开始、结束、记分；任何登录用户可读比赛、报名、看实时与汇总。
- **报名容量**：`maxPlayers > 0` 时按人数限制；开始后不能再报名/退赛。
- **实时**：客户端每 4 秒 `GET /live?since=<updatedAt>`；无变化时服务端只回 `changed:false`，不传文档。人数/状态变化用同一接口的 `updatedAt` 触发重渲染。要更低延迟可换 WebSocket（`/ws/races/{id}`），当前实现优先简单可靠。
- **分享链接**：`https://<host>/h5/#/join/<joinCode>`，只暴露报名码，不含用户信息。

## 3. 数据

| 表 | 说明 |
| --- | --- |
| `users` | `id`（`wx_<openid>` 或 `dev_<deviceId>`）、昵称 |
| `tokens` | 登录令牌（Bearer） |
| `races` | 比赛文档 + `join_code` / `status` / `max_players` |
| `participants` | `(race_id, user_id)` 唯一，记录报名姓名/性别/水平 |

`race.status`：`draft`（未开放）→ `open`（报名中）→ `playing`（进行中）→ `done`（已结束）。

## 4. 场馆与导航

- 场馆由管理员在 H5 的「场馆」页维护：名称、地址、经纬度（默认 `gcj02`，与高德/腾讯一致）、备注。
- 创建比赛时选择场馆，比赛文档保存**场馆快照**，之后改场馆不会影响已创建的比赛。
- 报名页与比赛页都显示「时间 / 场馆 / 地址」，点「导航」：
  1. 微信内且配置了公众号 → `wx.openLocation` 打开微信内置地图（可直接选导航 App）；
  2. 其他环境 → 高德 URI `uri.amap.com/navigation?...&coordinate=gaode&callnative=1`，
     已装高德则唤起 App，否则打开网页地图；
  3. 只有地址没有坐标 → 复制地址并提示粘贴到地图 App。

`/api/wechat/jssdk` 需要 `access_token` 与 `jsapi_ticket`（服务端已缓存），
公众号后台还需把 H5 域名加入 **JS 接口安全域名**。
