# 猩球 · 羽球局

朋友局用的羽毛球比赛工具：**选赛制 → 生成链接 → 微信登录报名 → 记分 → 实时比分 → 汇总排名**。

- 客户端：H5（微信内直接打开，也可加到桌面），无构建步骤。
- 服务端：Python / FastAPI + SQLite，单文件数据库，一条命令启动。
- 规则：计分、让分、局数、追分、排名链从原小程序「羽毛球助手」（appid `wx5f3f808a2ea7f0a8`）反编译还原，出处见
  [docs/规则还原.md](docs/规则还原.md)；逆向过程见 [docs/逆向分析.md](docs/逆向分析.md)。

## 快速开始

```bash
# 1. 服务端
cd server
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 18000
```

打开 <http://127.0.0.1:18000/> → 自动跳转 H5。

手机真机测试：电脑与手机连同一个 WiFi，手机浏览器打开 `http://<电脑局域网IP>:18000/`。
用 `--host 0.0.0.0` 才能被其他设备访问；端口被系统占用时换一个（如 8090）。

**同一台设备模拟多人**（一个浏览器多标签即为同一个用户）：
给每个标签加 `?device=` 参数，各自成为独立用户，互不影响：

```
http://<IP>:18000/h5/?device=demo1#/join/ABC123
http://<IP>:18000/h5/?device=demo2#/join/ABC123
```

身份隔离在 `sessionStorage`（标签页级），不加参数时仍用浏览器级身份。

```bash
# 2. 测试
npm test                      # 规则 + 数据层端到端
cd server && python -m pytest -q
```

微信登录（已接入，配好即生效）：复制 `server/.env.example` 为 `server/.env`，填
`GORILLA_WECHAT_APPID` / `GORILLA_WECHAT_SECRET` / `GORILLA_OAUTH_CALLBACK` 后，
微信内打开 H5 会自动走公众号网页授权（静默），其他环境或未配置时用设备号登录。
`/api/health` 的 `features.wechatOAuth` 表示是否已启用。
**要申请什么、花多少钱、几天能开通**：[docs/开通微信登录.md](docs/开通微信登录.md)。
详见 [docs/微信登录与流程.md](docs/微信登录与流程.md)。

## 管理员

首个登录的用户自动成为管理员；也可用 `GORILLA_ADMIN_DEVICES=deviceA,deviceB` 指定。
管理员在首页右上角「后台」进入独立后台页 `h5/admin.html`（玩法 + 场馆），非管理员会被拦截并提示输入**管理员口令**
（服务端 `GORILLA_ADMIN_CODE`，验证一次永久生效）。后台是桌面优先布局，宽屏两列、窄屏自动单列。

## 一条完整的使用流程

1. 管理员打开 H5 → 「新建」→ 填时间、选场馆、选类型与赛制（19 种）、局数、分制、排名方式 → 创建。
   报名方式二选一：「报名制（生成链接）」或「直接开打（现在就加人）」；报名制创建时不用填选手。
2. 比赛页点「开放报名」→ 生成报名码与链接 → 「复制报名链接」发到群里。
3. 成员点链接 → 微信授权（或填名字）→ 报名；管理员页面每 4 秒自动刷新报名名单。
4. 人齐后点「开始比赛」→ 用报名名单生成对阵。
5. 记分：逐球 +/−、快捷比分、让分、局数判定、追分模式；每局比分实时写服务端。
6. 队员在比赛页看实时比分与排名（轮询，无需刷新）。
7. 管理员「结束比赛」→ 汇总最终排名 + 每场比分。

## 功能

| 模块 | 说明 |
| --- | --- |
| 登录 | 微信网页授权（可选）/ 设备号；令牌失效自动重登 |
| 玩法 | 玩法是代码模块（`shared/plays/*.js`），可插拔；已迁移 9 个（八人转、混双转、前后转、固搭转、单打转、单/双循环、擂台、追分赛），其余内置赛制仍可用 |
| 后台（独立页） | `h5/admin.html`：玩法管理（五段规则/默认值/启停/LLM 新增引导）+ 场馆管理；非管理员访问被拦截 |
| 创建比赛 | 选择玩法时直接展示「参与人数 / 怎么玩 / 怎么分组 / 怎么结束 / 怎么计分」；可选**场地数**，多场地时并行排赛（每轮按场地数封顶） |
| 权限 | 管理员 > 创建者 > 成员 > 访客：管理员可见全部比赛与实时比分、可强制结束；访客报名后才可看对阵与比分 |
| 报名 | 报名码 + 链接、人数上限、报名名单、实时刷新、开始后锁定 |
| 场馆 | 管理员维护场馆（名称/地址/经纬度），建赛时选择；报名页与比赛页一键导航。**粘贴高德分享链接可自动填名称/地址/坐标**。首次启动自动种入「超级鹰羽毛球馆(268店)」「菁英梦谷·常营12号楼」 |
| 时间 | 建赛时选择日期时间，首页/报名页/比赛页统一展示 |
| 记分 | 局数 1/3/5、分制 7–42、2 分差、30 分封顶、让分表、追分模式、快捷比分 |
| 排名 | 4 种排序（积分/净胜分/总得分/胜场），按个人或按队伍 |
| 汇总 | 最终排名 + 已结束场次比分 |
| 战绩 | 按名字跨比赛统计场次与单/双打胜率 |

## 目录

```
h5/                 H5 客户端（index.html / app.css / js/{api,store,app}.js）
shared/             纯逻辑：rules（计分/让分/积分）、ranking（排名）、formats（排程原语）
shared/plays/       玩法模块：每个玩法一个文件 + registry.json（新增玩法只动这里）
server/             FastAPI：app/{main,db,rules}.py + tests/
tests/              logic.test.js（规则）、e2e.test.js（客户端数据层 ↔ 服务端）
assets/logo/        品牌图标各尺寸（32/48/64/96/128/144/180/192/256/384/512/1024 + favicon.ico）
tools/wxapkg.py     微信 PC 端 wxapkg 解密解包（逆向用）
docs/               逆向记录、规则出处、接口、微信登录、LLM 玩法开发指南（docs/llm/）
```

`shared/*.js` 同时支持 `require()` 与浏览器 `<script>` 直接加载：H5 通过
`/shared/...` 引用同一份文件，规则只有一处实现。

## 边界

- 不含原小程序的俱乐部、会费、支付、保险、广告等依赖资质与第三方 SDK 的功能。
- 实时比分用 4 秒轮询（简单、跨网络稳定）；需要更低延迟可加 WebSocket。
- 数据库默认 SQLite 单文件，`server/app/db.py` 是唯一持久化入口，换 Postgres 只改这一层。
